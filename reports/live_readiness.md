# 实盘准备度：约束、验收标准与判定

> 用途已明确：**自己的钱，自己实盘**。所以判据不是"收益高"，而是
> **"敢不敢拿真钱跑"**——能重复、容量够、回撤可承受、逻辑说得清。
>
> 本文件是决策记录，先定约束和门槛，再看候选能不能进。**门槛先定、后看结果**，
> 否则一定会被"看起来最好的那个"带着走。

## 1. 约束（已定，不再改）

| 项 | 取值 | 依据 |
|---|---|---|
| 资金 | 100 万，单账户 | 现有回测口径；也是"容量上限约 1 亿"的 1/100，留足余地 |
| 方向 | 只做多 | 融券成本高、券源不稳，做空在个人账户不可复制 |
| 杠杆 | 不用 | 低波组合波动只有 12.9%，加杠杆看似诱人，但需融资成本模型，现在没有 |
| 持仓数 | 40~80 只 | <40 抽样误差过大（随机 50 只的 σ≈2.6pp/5年）；>100 时单只 1 万，最低佣金 5 元 ≈8bp，固定成本吃掉收益 |
| 单票上限 | 2.5% | 100 万 / 40 只；避免单票黑天鹅 |
| 调仓频率 | 月频 | 周频/日频换手成本高且信号噪声大；已验证月频换手 3.0~22.4 倍（5年） |
| 行业偏离 | ±5pp（相对基准） | 低波的教训：不限行业会 30.6% 压在银行上，收益 100% 由行业解释 |
| 不做 | 日内、融资、期权、ST、次新（上市 <60 日）、停牌 | 已有实现与测试 |

## 2. 验收门槛（硬指标，缺一不进）

一个策略要能进实盘，必须**同时**满足：

| # | 门槛 | 数值 | 理由 |
|---|---|---|---|
| 1 | 样本外相对收益 | 两个独立时段都不低于同期**宇宙等权 -2pp** | 跑不赢"什么都不做"就没有存在意义 |
| 2 | 样本外 Sharpe | ≥ 0.50 | 0.5 对应年化/波动 ≈ 1:2，实盘能承受 |
| 3 | 最大回撤 | ≤ 同期等权基准的 0.8 倍 | 实盘最怕的是回撤不是收益 |
| 4 | 时段一致性 | ≥ 2 个独立时段方向一致 | 只有一段好 = 那次是运气 |
| 5 | 参数个数 | ≤ 3 | 参数越多越像拟合；低波那个 60 日窗口 + k 已经是 2 个 |
| 6 | 逻辑可解释 | 一句话说清赚什么钱 | 说不清就不能在回撤时拿住 |
| 7 | 容量 | 100 万下 5% 分位容量 ≥ 1,000 万 | 留 10 倍冗余，防止策略失效前先被规模搞死 |

**不满足就不实盘。** 满足的最多用 **20% 资金试跑 3 个月**，期间不改参数；
3 个月后再看是否加到 100%。

## 3. 三段对照矩阵

"样本内"= 2020-2024（策略就是在这段上想出来的），"样本外 1"= 2015-2019，
"样本外 2"= 2025-01-02 ~ 2026-10-20（最近 433 个交易日，与实盘衔接）。

| 候选 | 样本内 2020-2024 | 样本外1 2015-2019 | 样本外2 2025-2026 |
|---|---|---|---|
| **中证1000** | +1.01% | -1.71% | **+9.44%** |
| 等权 50 只 | +9.15% / 0.489 / -36.0% | -12.70% / -0.294 / -73.1% | +4.32% / 0.328 / -26.0% |
| 低波·行业中性 | +9.74% / **0.679** / -22.5% | -10.33% / -0.401 / -60.8% | +2.21% / 0.246 / **-19.7%** |
| 12-1 动量 | -22.86% / -0.731 | -25.56% / -0.973 | -9.26% / -0.172 |
| 60 日反转（skip=0） | +3.27% / 0.255 | -8.58% / -0.118 | **+11.63% / 0.614** |
| 60 日反转（skip=5） | +0.08% / 0.142 | -10.30% / -0.190 | 未跑 |

（年化 / Sharpe / 最大回撤）

**最要紧的一行是中证1000**：2020-2024 的 +1.01% 到 2025-2026 的 +9.44%，
而同期"宇宙等权"只有 +4.32%——**等权/小市值溢价又是一次反向**。
三段里它变了两次符号：+8.1pp → -11.0pp → -5.1pp。

## 4. 判定：一个都不过

逐条对照第 2 节的门槛：

| 候选 | #1 相对宇宙等权 | #2 Sharpe≥0.5 | #3 回撤≤0.8× | #4 时段一致 | 结论 |
|---|---|---|---|---|---|
| 等权 50 只 | ✗ (-2.4 / -5.3 / -0.6pp) | ✗ 只有 1 段 | ✗ | ✗ | 不合格 |
| 低波·行业中性 | ✓ +0.6 / ✓ +2.4 / ✗ -2.1pp | ✗ 只有 1 段 | ✓ 0.63 / ✗ 0.83 / ✓ 0.76 | ✗ | 不合格 |
| 12-1 动量 | ✗ 三段全负 | ✗ | — | ✓ 稳定为负 | 不合格（但"不要追动量"可用） |
| 60 日反转(skip0) | ✗ -5.9 / ✓ +4.1 / ✓ +7.3pp | ✗ 只有 1 段 | ✗ | ✗ | 不合格 |

**结论：现在不该拿钱跑任何东西。** 框架的价值之一就是在亏钱之前告诉你
"还没有能跑的东西"——这比给你一个样本内 9.74%、样本外 -10% 的"策略"有用。

### 4.1 三段里唯一稳定的只剩一件事

**动量亏钱**：-22.9% / -25.6% / -9.3%，三段全负，且都远低于同期指数。
这是可以直接用的负面筛选：**不要买过去三个月涨幅榜前列的票。**

（另一条"低波回撤更小"经检验不成立，见 4.2。）

### 4.2 "低波当风控底仓"也不成立——回撤保护就是降 beta

原本以为低波的价值在"少受回撤"。要验证它是不是只是"仓位轻"，做一个
**beta 匹配对照**：用日收益回归出低波对等权的 beta，构造
`beta × 等权 + (1-beta) × 现金`（现金 2%/年，国债逆回购/货币基金的水平），
在同一 beta 下比较。

| 时段 | 低波 beta | 组合 | 年化 | 波动 | Sharpe | 最大回撤 | 卡玛 | 最长水下(交易日) |
|---|---|---|---|---|---|---|---|---|
| 2020-2024 | 0.552 | 低波 | 9.74% | 15.44% | 0.631 | -22.47% | 0.433 | **677** |
| | | 等权 | 9.15% | 23.67% | 0.387 | -36.02% | 0.254 | 350 |
| | | **beta 匹配** | 6.63% | 13.06% | 0.507 | **-21.11%** | 0.314 | 325 |
| 2015-2019 | 0.661 | 低波 | -10.33% | 21.42% | -0.482 | -60.84% | -0.170 | 1111 |
| | | 等权 | -12.70% | 30.36% | -0.418 | -73.09% | -0.174 | 1111 |
| | | **beta 匹配** | -7.00% | 20.08% | -0.349 | **-55.34%** | -0.126 | 1111 |
| 2025-2026 | 0.492 | 低波 | 2.21% | 11.68% | 0.190 | -19.71% | 0.112 | 171 |
| | | 等权 | 4.32% | 17.72% | 0.244 | -25.97% | 0.166 | 175 |
| | | **beta 匹配** | 3.54% | 8.72% | 0.406 | **-13.13%** | 0.270 | 156 |

低波减去 beta 匹配组合的净效果：

| 时段 | 年化差 | Sharpe 差 | 回撤差 | 卡玛差 |
|---|---|---|---|---|
| 2020-2024 | **+3.12pp** | +0.124 | **-1.36pp（回撤更大）** | +0.120 |
| 2015-2019 | -3.33pp | -0.134 | **-5.50pp（回撤更大）** | -0.043 |
| 2025-2026 | -1.33pp | -0.217 | **-6.58pp（回撤更大）** | -0.158 |

**三段里，同一 beta 下低波的回撤都比"少持股 + 现金"更大，波动也更大。**
只有 2020-2024 一段的收益和 Sharpe 更高，而那段已经查明是行业配置
（银行 30.6%）+ 低 beta 风格占优，样本外不重复。

换成**波动率匹配**（更公平：控制总风险而不是只控 beta，持股比例 65%/71%/66%）结论一样：

| 时段 | 波动匹配 年化 | 低波 年化 | 年化差 | Sharpe 差 | 回撤差 | 卡玛差 |
|---|---|---|---|---|---|---|
| 2020-2024 | 7.29% | 9.74% | **+2.45pp** | +0.159 | **+2.22pp（低波更好）** | +0.138 |
| 2015-2019 | -7.70% | -10.33% | -2.63pp | -0.123 | -2.74pp（更差） | -0.037 |
| 2025-2026 | 3.89% | 2.21% | -1.68pp | -0.144 | -2.19pp（更差） | -0.110 |

两种归一化（beta / 波动率）在**两个样本外时段结论一致：低波不如"等权+现金"**。
只有 2020-2024 —— 也就是策略被设计出来的那一段 —— 低波在四项上全胜。

上下行捕获（月度，以等权为基准）：

| 时段 | 上行捕获 | 下行捕获 | 是否防御 |
|---|---|---|---|
| 2020-2024 | 0.70 | 0.59 | 是 |
| 2015-2019 | 0.55 | **0.64** | **否（下行跌得更多）** |
| 2025-2026 | 0.44 | 0.41 | 勉强 |

**结论：低波的回撤保护 100% 来自 beta 更低，没有额外防御效应。**
要降风险就直接降仓位——同样风险水平下回撤更小、波动更低、Sharpe 更高（后两段），
还省掉选股、换手和佣金。用低波去当"风控底仓"是多绕一步，而且效果更差。

### 4.3 那"降风险"该怎么做

同一个脚本给出的答案很直接：**w × 等权 + (1-w) × 现金**，按目标波动选 w。

| 目标波动 | 股仓 | 2020-2024 年化/回撤 | 2025-2026 年化/回撤 |
|---|---|---|---|
| 24%（满仓等权） | 100% | 9.15% / -36.0% | 4.32% / -26.0% |
| 15% | 65% | 7.29% / -24.7% | 3.89% / -17.5% |
| 12% | 49% | 6.63% / -21.1% | 3.54% / -13.1% |

**这就是全部**——不需要选股、不需要月频换手、不需要行业中性化。
一个 65% 股票 + 35% 现金的账户，在两个样本外的风险调整后表现都好于低波精选组合。
实盘的"风控"应该落在仓位管理上，不是落在因子上。

（现金按 2%/年计。若用国债逆回购/货币基金实际可达 1.5%~2.5%，结论不变。）

另一个实盘细节：2020-2024 低波最长水下 **677 个交易日**（约 2.7 年），
而 beta 匹配只有 325 天。实盘中"三年不赚钱"是极难拿住的，这一点比年化更致命。

工具：`scripts/lowvol_defensive_check.py`，明细 `reports/lowvol_defensive.json`。

### 4.4 那"什么时候降仓位"？——择时也不成立

既然降风险靠仓位，下一个问题就是何时降。用中证1000 的历史构造四条常见规则，
月末给信号、下月持有，与固定仓位对照（`scripts/position_rule_check.py`）：

| 规则 | 2020-2024 年化/回撤/卡玛 | 2015-2019 | 2025-2026 |
|---|---|---|---|
| 固定 100% | 10.73% / -31.5% / 0.341 | -4.13% / -63.8% / -0.065 | 13.55% / -21.4% / 0.632 |
| **固定 65%** | 9.23% / -21.5% / 0.430 | -0.60% / -44.2% / -0.014 | 9.98% / -14.3% / 0.700 |
| **固定 50%** | 8.41% / -18.1% / 0.465 | **+0.47% / -34.0% / +0.014** | 8.28% / -11.0% / 0.751 |
| ma200（跌破年线减半） | 10.35% / -20.9% / **0.495** | -2.04% / -54.5% / -0.037 | 12.04% / -21.4% / 0.562 |
| mom12（12 月动量为正才满仓） | 9.12% / -27.6% / 0.331 | -1.23% / -54.5% / -0.023 | 15.33% / -21.4% / 0.715 |
| dd10（回撤超 10% 减半） | 8.75% / -20.9% / 0.418 | -1.82% / -54.5% / -0.033 | 10.64% / -22.8% / 0.466 |
| vol_target（目标波动 15%） | 7.09% / -27.6% / 0.257 | -4.74% / -62.4% / -0.076 | 16.22% / -16.7% / **0.969** |

**没有一条规则三段都赢。** 而且最关键的一行在 2015-2019：

> **固定 50% 是唯一赚钱的（+0.47%），所有择时规则都亏钱。**

那一段是持续四年的下跌+反弹，任何"信号触发后保持高仓位"的做法都挨打，
而"什么都不判断、只拿一半"反而是最好的。

2025-2026 那列的 mom12 / ma200 不能算数：样本只有 373 个交易日，
200 日均线和 12 月动量几乎全程处在暖机期，平均仓位 92.7% / 98.6%，
等于没触发过。

**结论：择时也没有通过检验。** 实盘只剩一个决策——**你能承受多大回撤，
就配多少仓位**，不需要判断市场。

### 4.5 仓位怎么定（实盘唯一需要的参数）

三段数据里，回撤与仓位近似成正比：

| 仓位 | 2020-2024 回撤 | 2015-2019 回撤 | 2025-2026 回撤 | 回撤/满仓回撤 |
|---|---|---|---|---|
| 100% | -31.5% | -63.8% | -21.4% | 1.00 |
| 65% | -21.5% | -44.2% | -14.3% | 0.66~0.69 |
| 50% | -18.1% | -34.0% | -11.0% | 0.51~0.57 |

**估算公式：回撤 ≈ 仓位 × 满仓回撤**（略偏乐观，因为回撤非线性）。

实盘用法：先决定"最坏情况能接受多少回撤"，再倒推仓位——

| 能接受的最大回撤 | 按 2015-2019 那种熊市算的仓位 | 按 2020-2024 算 |
|---|---|---|
| -15% | 23% | 48% |
| -25% | **39%** | 79% |
| -35% | 55% | 满仓 |

保守起见应该用最坏样本（2015-2019）。也就是说：**愿不愿意承受 -25%，
对应的就是四成仓**。这就是全部的风控决策，不需要任何因子。

### 4.6 如果最后就买"宇宙等权"，100 万够不够

三段检验下来，没有任何选股/择时策略能稳定跑赢宇宙等权。那就剩一个现实问题：
**100 万买不了 4700 只，抽多少只才够像。** 三个约束互相拉扯：

**① 跟踪误差**（200 次随机抽样，与宇宙等权比）：

| N | 2020-2024 TE | 2015-2019 TE | 2025-2026 TE | 5 年累计偏离 5%~95% |
|---|---|---|---|---|
| 50 | 6.79% | 6.37% | 6.96% | -17.6% ~ +16.7% |
| 100 | 4.71% | 4.52% | 4.81% | -11.0% ~ +11.1% |
| 200 | 3.31% | 3.11% | 3.36% | -9.5% ~ +8.5% |
| 400 | 2.32% | 2.13% | 2.28% | -5.1% ~ +7.0% |

TE 大致按 1/√N 下降。N=50 时五年累计偏离可达 ±17%——**你无法判断是自己选得好
还是抽样运气**，这已经大于任何因子的 alpha。

**② 最低佣金的固定成本**（100 万 / N，单笔最低 5 元）：

| N | 每只金额 | 单边佣金占比 | 每月全换手的年化成本 |
|---|---|---|---|
| 50 | 20,000 | 0.025% | 0.60% |
| 100 | 10,000 | 0.050% | 1.20% |
| 200 | 5,000 | 0.100% | 2.40% |
| 400 | 2,500 | 0.200% | 4.80% |

（"每月全换"是最坏情况；若**固定样本、季度再平衡**，换手主要是权重漂移，
N=100~200 的实际成本约 0.1%~0.3%/年。）

**③ 整手约束——最容易忽略的一条**：

| N | 每只金额 | 能买的最高股价 | 实际可买股票占比 |
|---|---|---|---|
| 50 | 20,000 | 200 元 | 99.5%~99.8% |
| 100 | 10,000 | 100 元 | 98.2%~99.2% |
| 200 | 5,000 | 50 元 | 93.2%~96.0% |
| 400 | 2,500 | 25 元 | 77.9%~86.2% |

N=400 时有 14%~22% 的股票**根本买不了**（股价 > 25 元，一手就要 2500 元以上）。
这不只是少几只标的，而是系统性偏向低价股——低价股在 A 股本身有独立的风格收益。

**结论：100 万本金下，N 的可用区间是 100~200。**
- N=100：TE 4.7%、可买 98%、季度再平衡成本 ~0.1%
- N=200：TE 3.3%、可买 93%、成本 ~0.3%

再往上（N=400）TE 只降到 2.3%，但 20% 的股票买不到、成本翻倍，不划算。

工具：`scripts/replicate_universe.py`。

## 5. 现在能做什么，还缺什么

**研究侧已经走到底了**：选股（动量/反转/低波，含行业中性）全败，择时（4 条规则）全败，
只剩"按仓位控制回撤"这一条，而它不需要任何模型。而唯一没碰过的信息源
（估值/股息）已明确不做——所以"能不能靠选股赚钱"这个问题，用现有数据无法再推进。

**剩下的都是工程缺口**（做完就能实盘，但不会提高收益预期）：

| # | 事项 | 状态 | 说明 |
|---|---|---|---|
| 1 | `live_signal.py` | **已完成** | 固定样本 + 整手定量 + 与持仓差分，见第 7 节 |
| 2 | 抽样固定化 | **已完成** | `live/sample.json` 存完整 1000 只排序，退市按名次补位 |
| 3 | 每日增量更新 | 缺 | 现在是一次性全量拉；实盘要每天 15:30 后更新 bars/status |
| 4 | 监控与熔断 | 部分 | 已有：数据新鲜度、现金不足、样本不足、非季度月、成本估算。缺：成交回报对账、净值偏离预期、连续亏损停止 |

> 剩下的两项都是"跑起来才有用"的东西：增量更新要接行情源，监控要接成交回报。
> 在真的下单之前，先手动跑一遍 7.4 的流程，确认数据、数量、成本都符合预期。

**如果还要做研究**，只有两个方向没试过，都需要新数据：
- 场内 ETF / 指数基金的历史数据（做跨资产、跨风格配置，不依赖个股 alpha）；
- 分钟级数据（做开盘可成交量估计，把容量口径从"全日量"修正到"开盘量"）。

## 6. 结论：实盘该怎么做

如果现在就下单，按本文件全部检验结果，唯一站得住的方案是：

1. **不选股**——等权持有 N=100~200 只（按 4.6 固定样本、季度再平衡）；
2. **不择时**——不判断市场方向，4 条规则都没通过；
3. **只调仓位**——按能承受的回撤定 w（4.5 的表），保守用最坏样本；
4. **不追动量**——三段全负，可作负面筛选。

预期是"**跟上这个市场，回撤可控**"，不是"跑赢"。任何声称能跑赢的做法，
在本项目的三次样本外检验里都没有成立过。

## 7. 执行流程（`live_signal.py`）

上面的结论已经落成脚本。它**不做任何选股判断**，只负责把「固定样本 + 仓位」
翻译成委托单，分两步：

```bash
# ① 只做一次：冻结样本。之后永不重抽。
python scripts/live_signal.py --data-dir data/processed_2025_2026 \
```

### 7.1 为什么样本必须冻结

股票池每个月都在变（新股上市、退市）。若每次都按 `sha1(symbol)` 重排取前 N，
截断位置会随池子变化而移动，等价于**每次重新抽一次**——实测会让整批组合被换掉，
年化差 1.8pp，全是抽样噪声。这与「给默认值加参数化导致 seed=0 也换仓」是同一个坑。

所以 `live/sample.json` 存的是**完整 1000 只的排序**，前 100 只入选；
某只退市/变 ST 时按名次顺位补人（确定，不重抽）。**这个文件不要再改**，
换了它等于换了一套组合，历史回测结果对不上。

### 7.2 几条硬规则（都有单测）

| 规则 | 原因 |
|---|---|
| 买入必须是 100 股整数倍 | 交易所规定 |
| 卖出也必须是 100 股整数倍 | 上证函〔2014〕301 号；**只有清仓可以带零股** |
| 单笔 < 2000 元不下单 | 100 万 / 100 只 = 4000 元/只时，最低佣金 5 元已占 0.125% |
| 停牌/跌停持仓冻结 | 算进仓位、不下单；否则会拿它的市值再买一遍别的票 |
| 样本外持仓清仓 | 否则组合慢慢偏离成"样本 + 一堆历史遗留" |
| 同一天重复跑必须零订单 | 幂等；否则每次跑都白交佣金 |
| 数据超过 15 天未更新则拒绝出信号 | 静默用旧价格出单是实盘最危险的错误 |

### 7.3 仓位怎么填

`--position` 直接取 4.5 节的表。**保守用最坏样本（2015-2019）**：

| 能接受的最大回撤 | position |
|---|---|
| -15% | 0.23 |
| -25% | 0.39 |
| -35% | 0.55 |

100 万 / `position=0.40` / N=100 时：每只约 4,000 元，单边佣金 0.125%（最低 5 元），
建仓一次成本约 0.18%。若嫌贵，把 N 降到 50~80（每只 5,000~8,000 元）。

### 7.4 收盘后到下单的动作

1. 15:30 后更新数据（`build_dataset`）；
2. 跑本脚本，得到 `orders.csv`；
3. **先卖后买**（A 股卖出资金当日可用于买入），按 `orders.csv` 的顺序执行；
4. 成交后更新 `live/holdings.csv`（`symbol,shares`），下次调用要读它。
