## 2. 发现的问题

### P0（高，已修）暖机期被计入绩效与超额，改变了样本外结论

**现象**：每段回测开头都有一段净值恒等于初始资金的空仓期，长度固定：

| 段 | 空仓交易日 | 首次建仓 | 同期中证1000 |
|---|---|---|---|
| 2015-2019 | **78** | 2015-05-04 | **+69.76%** |
| 2020-2024 | **79** | 2020-05-06 | +2.22% |
| 2025-2026 | 78 | 2025-05-06 | 待补 |

**原因**：回测起点由数据起点决定，而 `min_list_days=60` 要求上市满 60 个交易日
才入池。数据从 2015-01-05 开始时，前 60 个交易日的股票池是空的——不是策略选择，
是数据起点 + 暖机规则的副产物。

**危害**：
1. 这 78 天的 0 收益被计入年化分母，压低年化；
2. 同期基准是活的，**基准的涨跌照常计入超额**——2015 年那 69.76% 被白拿，
   直接把样本外超额压低 70 个百分点；
3. beta / TE 也被污染：约 6% 的样本是"策略 0 收益 vs 基准有涨跌"的伪配对。

**修正前后对照**（同一份数据、同一份策略）：

| 段 | 指标 | 修正前 | 修正后 |
|---|---|---|---|
| 2020-2024 等权 | 年化 | 9.15% | **9.33%** |
| | 超额 | +7.43% | **+8.41%** |
| | TE | 13.29% | **10.35%** |
| | IR | 0.560 | **0.813** |
| | beta | 0.807 | **0.920** |
| | 基准年化 | +1.01% | +0.59% |
| 2015-2019 等权 | 年化 | -12.70% | **-13.75%** |
| | 基准年化 | -1.71% | **-12.66%** |
| | 超额 | -11.0pp | **-1.19pp** |
| | IR | 待查 | **-0.188** |
| 2015-2019 低波中性 | 年化 | -10.33% | **-11.19%** |
| | 超额 | 待查 | **-0.77pp** |
| | IR | 待查 | **-0.058** |
| 2025-2026 等权 | 年化 | +4.32% | **+3.88%** |
| | 基准年化 | +9.44% | **+7.63%** |
| | 超额 | -5.1pp | **-4.50pp** |

**最重要的变化在基准**：2015-2019 的中证1000 从 **-1.71% 变成 -12.66%**。
因为旧数字从 2015-01 起算（含 1-4 月 +69.8% 的大牛市），而策略 5 月才建仓。
**旧口径是"策略 5 月入场、基准 1 月入场"的对比，不公平。**

**修法**：`metrics.performance.trim_warmup` —— 优先按持仓表取首次持仓日，
无持仓表时按"开头连续等于初始值且长度 ≥2"判定；截掉的前缀不计入
年化/波动/夏普/超额，但保留在 `equity_curve` 与 `cumulative_return` 里。
新增 `warmup_days` / `effective_days` / `first_active_date` 三个字段写进
`metrics.json`，让"统计从哪天开始"变成显式信息。

新增 4 项测试（`test_metrics.py`）。

| 全宇宙月频等权（对齐窗口） | +4.96% | -4.56% | +4.07% |

**读法必须改**：

- 2015-2019 不是"策略崩了"，而是**策略与基准一起亏了 12~13%**，超额 -1.19pp、
  IR -0.19，统计上与 0 没有区别。旧文档写"比同期等权还差"，是把暖机期算进去的
  产物，现已不成立。
- 2020-2024 的超额比旧口径更强（IR 从 0.56 升到 0.81），因为去掉了 79 天
  "策略空仓、基准上涨"的拖累。
- 2025-2026 仍然跑输 4.5pp（IR -0.335），这一段结论不变。
- **"三段方向一致"仍然不满足**（+8.41 / -1.19 / -4.50），所以
  `live_readiness` 的"不通过"判定不变。但理由从"样本外大幅失效"改成
  "两段跑输或持平、一段跑赢，无法确认稳定超额"。

## 4. 尚未解释的差异（存疑）

### 4.1 2015-2019 引擎比同窗口宇宙等权低约 9pp

对齐窗口（2015-05-04 ~ 2019-12-31）：

| 口径 | 年化 |
|---|---|
| 引擎（50 只散列抽样，含成本） | -13.75% |
| 引擎（零成本） | -12.36%（成本只解释 0.34pp） |
| 全宇宙月频等权（同窗口、同过滤） | -4.56% |

差 9.2pp，而随机 50 对的抽样标准差约 2.7pp，是 3.4σ。**已排除**：成本（0.34pp）、
停牌标记缺失（不存在）。**未排除**：2015 年大量停牌导致的可交易池收缩、
月度调仓日的开盘成交价格、以及抽样本身的偏度。这一条不阻塞实盘，但需要专项核查,
在那之前"2015-2019 段"的所有数字（包括基准）都应按"有已知残差"读。

### 4.2 2020-2024 也存在同向差异

引擎 +9.33% vs 同窗口宇宙等权 +4.96%，差 4.4pp（1.7σ）。方向上引擎更好，
与 4.1 相反。两段都不解释的话，说明"随机 50 只 ≈ 宇宙等权"这个前提本身
需要重新确立。

## 6. 建议

1. **先解决 4.1**（2015-2019 的 9pp 残差）再谈任何"样本外"结论。它不是小事：
   如果引擎在该段系统性偏低，那么"低波样本外失效"的判定也可能被同一原因污染。
2. 4.1/4.2 的对策应该是同一个：把"随机 50 只 vs 宇宙等权"做成一个**可控实验**
   （同一调仓日、同一 universe、同一成交价口径，只差在持仓数），
   而不是继续用两套独立实现互相比。
3. P4/P5 属于体验问题，可以在下一轮顺手修。
4. **本次没有改任何策略参数**，所有历史实验的 `metrics.json` 保持原样（它们是
   当时口径的记录）。新旧数字不可直接混用，引用时务必说明口径。
