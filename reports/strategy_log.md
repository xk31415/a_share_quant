# 策略实验记录

> 每个策略都在同一份数据（2020-01-02 ~ 2024-12-31，4711 只主板+创业板）上跑，
> 统一成本假设、月频调仓、50 只等权、t+1 开盘撮合。
> 基准统一用**中证1000**（组合偏中小市值，用沪深300 会把风格收益误算成能力）。

## 1. 等权基准（随机 50 只）

|---|---|

## 一、为什么动量亏这么惨

先怀疑是 bug，用因子 IC 验了一遍：每个观测点算 60 日动量与**未来 20 日收益**的
横截面 Spearman 相关。

```
平均 IC   -0.0504
IC < 0    59.3% 的月份
IC 标准差 0.1582
ICIR      -0.318
```

**IC 为负且稳定**，说明不是代码错，是这个因子在本样本里方向就是反的。
A 股这个时段呈明显的短期反转特征：过去三个月涨得最多的票，下个月跌得最狠。

更极端的是几个月的 IC 达到 -0.40（2024-02）、-0.39（2024-04），对应动量崩塌月。

## 二、关键发现：方向不对称

如果只是"因子反向"，那把方向倒过来就该赚钱。但实测：

| | 年化 | 说明 |
|---|---|---|
| 买最强 50 | **-22.86%** | 赢家崩塌，跌得极狠 |
| 买最弱 50 | **+0.08%** | 输家不涨，基本持平 |

**负 IC 全部来自"赢家崩"，不是"输家涨"。** 这解释了为什么反向也赚不到钱：
A 股没有便捷的做空，你只能买"输家"，而输家只是不跌，不会涨。

这个不对称也有现实解释：涨幅榜前列的股票往往伴随涨停、题材、高换手，
下个月回吐；而跌幅榜的股票多是基本面恶化，不会因为"跌多了"就反弹。

## 三、结论与下一步

- 12-1 动量在 A 股 2020-2024 **不可用**，无论正向反向；
- 但这个负结果本身有价值：**框架能正确识别一个坏因子**。如果框架有 bug
  （比如信号用了未来数据），动量这种"热门股"策略通常会跑出漂亮的假收益，
  而不是 -71%。这个结果反过来印证了防未来函数的处理是有效的；
- 换手率 31.7（等权基准 3.0）暴露了另一个成本：月频全换仓在动量上代价很高，
  即使因子本身没方向，光交易成本也能吃掉 0.64%/年。

下一步候选（按我的判断排序）：

1. **反转因子**（20 日超跌 + 剔除ST/停牌 + 流动性约束），而不是 60 日动量的反向——
   短周期反转在 A 股文献里更稳定，且和上面的 IC 结论方向一致；
2. **低波/低换手**组合，先验证"低风险异象"在 A 股是否存在；
3. **价值因子**需要 PE/PB 数据，目前 `instruments` 没有，要补一列。
