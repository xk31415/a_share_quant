# 策略实验记录

> 同一份数据（2020-01-02 ~ 2024-12-31，4711 只主板+创业板，511 万行），
> 统一成本假设、月频调仓、50 只等权、T+1 开盘撮合、初始资金 100 万。
> 基准统一用**中证1000（000852）**，代码 `EXP-20261020-*` 可在 `results/` 复核。
>
> **基准序列在 2026-10-20 修正过一次**：`000905`/`000852` 与个股代码撞车
> （厦门港务、石化机械），旧的超额数字偏低。本文的数字全部是修正后的。
> 详见 `fix_log.md` 第十三节。

## 0. 最重要的参照系：等权口径本身值 8.72%

这一栏不是策略，是所有等权策略的**及格线**。用同一份后复权行情算，
月度调仓、等权、不计成本：

| 参照 | 年化 | 说明 |
|---|---|---|
| 全宇宙等权（3644~4711 只） | **8.72%** | 等权口径的"宇宙平均" |
| 随机 50 只 ×200 次 bootstrap | **8.37%**（σ=2.69pp） | 抽 50 只不改变收益，只引入噪声 |
| 中位成交额以上等权（约 1822 只） | **0.61%** | 剔掉不活跃的一半，收益几乎归零 |
| 中证1000（价格指数） | +1.01% | 市值加权，不含分红 |

**读法**：一个等权选股策略如果年化在 8.7% 附近，说明它只是在复制宇宙平均，
没有做任何选择。这一条比任何基准都重要——它把"选股能力"和"等权这个权重方案
本身的收益"分开了。

## 1. 等权基准（随机 50 只，散列抽样）

无因子。四个种子的持仓互不重叠（交集 0~1 只），年化落在 **6.99%~9.15%**，
极差 2.16pp，与下面 bootstrap 的 σ=2.69pp 一致。

| 指标 | 数值 |
|---|---|
| 累计 / 年化 | +52.30% / **9.15%**（种子 0） |
| 其余三个种子年化 | 7.11% / 7.42% / 6.99% |
| 波动 / Sharpe | 23.67% / 0.489 |
| 最大回撤 | -36.02% |
| 换手（5年累计） | 3.04 |
| 成本拖累 | 0.26%/年 |
| 超额（vs 中证1000） | **+7.43%**，TE 13.29%，IR 0.560，beta 0.807 |

> **一个复现性的坑**：加 `--seed` 支持时，散列键从 `sha1(symbol)` 改成
> `sha1(f"{seed}:{symbol}")`，于是 `seed=0` 也换了持仓，年化从 9.15% 掉到 4.55%，
> 而代码看起来只是多了一个默认参数。现已改成 `seed=0` 沿用原始散列，
> 并有测试 `test_seed_zero_keeps_original_hash_order` 锁住。
> 教训：**给"默认值"加参数化时，默认分支的输出必须逐位不变。**

**结论**：年化 7~9% 与"全宇宙等权 8.72%"基本一致，**没有选股能力**。
超额 +7.43% 来自等权放大微盘股权重，不是 alpha。详见 `fix_log.md` 第十四节。

## 3. 反向（买最弱 50 只）—— 不赚钱

| 配置 | 年化 | Sharpe | 超额 | IR |
|---|---|---|---|---|
| 60 日、skip 5 | +0.08% | 0.142 | -0.18% | -0.009 |
| 60 日、skip 0 | **+3.27%** | 0.272 | +2.93% | 0.149 |
| 10 日、skip 0 | -10.12% | -0.392 | -11.32% | -0.609 |

（60 日 skip 5 那档换手 40.35、成本拖累 0.92%/年、最大回撤 -43.67%。）

## 一、为什么动量亏这么惨

先怀疑是 bug，用因子 IC 验了一遍：每个观测点算 60 日动量与**未来 20 日收益**的
横截面 Spearman 相关。

```
平均 IC   -0.0504
IC < 0    59.3% 的月份
IC 标准差 0.1582
ICIR      -0.318
```

**IC 为负且稳定**，说明不是代码错，是这个因子在本样本里方向就是反的。
A 股这个时段呈明显的短期反转特征：过去三个月涨得最多的票，下个月跌得最狠。

更极端的是几个月的 IC 达到 -0.40（2024-02）、-0.39（2024-04），对应动量崩塌月。

## 二、关键发现：方向不对称

如果只是"因子反向"，那把方向倒过来就该赚钱。但实测：

| | 年化 | 说明 |
|---|---|---|
| 买最强 50 | **-22.86%** | 赢家崩塌，跌得极狠 |
| 买最弱 50（skip 5） | **+0.08%** | 输家不涨，基本持平 |
| 买最弱 50（skip 0） | **+3.27%** | 别跳过最近 5 日，好一些但仍打不过 8.72% |

**负 IC 全部来自"赢家崩"，不是"输家涨"。** 这解释了为什么反向也赚不到钱：
A 股没有便捷的做空，你只能买"输家"，而输家只是不跌，不会涨。

这个不对称也有现实解释：涨幅榜前列的股票往往伴随涨停、题材、高换手，
下个月回吐；而跌幅榜的股票多是基本面恶化，不会因为"跌多了"就反弹。

## 三、流动性分档：收益来源被完全定位

每个调仓日按调仓前 60 日均成交额把池子切成 5 档（各约 836 只），档内等权：

| 档位 | 年化 | 波动 | Sharpe |
|---|---|---|---|
| Q1 最不活跃 | **+22.16%** | 23.46% | 0.945 |
| Q2 | +15.76% | 24.04% | 0.656 |
| Q3 | +9.00% | 24.52% | 0.367 |
| Q4 | +2.42% | 25.14% | 0.096 |
| Q5 最活跃 | **-4.62%** | 25.33% | -0.182 |

五档单调递减、跨度 26.8pp，而各档波动几乎相同（23.5%~25.3%）。
这是流动性/规模溢价，不是抽样噪声。

**对策略的含义**：随机 50 只均匀落在五档，收益就是加权平均（≈8.7%）；
想去吃 Q1 的 22%，就必须刻意下沉到最不活跃的 800 只——那正是容量最差的区间。

## 四、结论

1. **12-1 动量在 A 股 2020-2024 不可用**，正向 -22.86%，反向也只有 +0.08%~+3.27%，
   都打不过"什么都不做"的 8.72%；
2. 这个负结果本身有价值：**框架能正确识别一个坏因子**。如果信号用了未来数据，
   动量这种"追热点"策略通常会跑出漂亮的假收益，而不是 -71%；
3. 换手率 31.7（等权 3.0）暴露成本：月频全换仓在动量上代价极高，
   即使因子没方向，光成本就吃掉 0.64%/年；
4. **所有等权策略必须先跟 8.72% 比**，再谈超额。只跟指数比会把等权溢价
   误读成能力——这是本项目踩过的最大一个坑。

下一步候选（按判断排序）：

1. **低波 / 低换手**：Q5（最活跃、通常也是高波动高换手）年化 -4.6%，
   Q1 年化 +22%，先验证"低风险异象"与流动性溢价能否分离；
2. **价值因子**（PE/PB）：需要补 `instruments` 的估值列，gm 的
   `get_instruments` 有现成字段；
3. **容量约束下的选股**：把 `max_participation_rate` 当硬约束进选股环节，
   而不是只在撮合时拦截——现版本会选出"根本买不够"的标的。
