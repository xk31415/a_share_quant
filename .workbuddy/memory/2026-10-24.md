**踩的坑（部署类通用）**：
1. `get_cash()` 返回 protobuf 不是 dict，`.get()` 炸 → 写 `_g()` 兼容两种
2. Windows 控制台 GBK，子进程输出中文变 `???` → `PYTHONIOENCODING=utf-8`
3. 简单 YAML 解析器没剥行内注释，`200  # 注释` 被当成字符串
4. `write_plan` 按**数据日**落盘，主控按**执行日**找文件，日期对不上
   → `find_recent_orders()` 按 mtime 找最近 24h 的 orders.csv
5. `a_share_quant` 包没 `pip install -e .`，live_signal 报 ModuleNotFoundError
6. PowerShell 反引号续行在 `powershell -Command` 里被吃 → 改单行
7. `order_cancel` 只收 1 个参数（dict），不是 (dict, account)

**安全约定**：
