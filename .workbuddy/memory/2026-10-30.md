# 2026-10-30

## 钉钉推送加涨跌幅 + 格式整理

改动都在 `live_auto.py` 的推送段（`trade_lines` / `settle_lines`）：

- 新增 `prev_bars(cfg, date)`：从 `bars.parquet` 取**严格早于 date 的最后一个交易日**
  的 close / limit_up / limit_down。刻意不用"最新一行"——T 日 08:30 才补到 T-1，
  正常运行两者等价，但数据漏更新时"最新一行"会变成 T-2，把两天涨跌算成一天。
- 新增 `basis_for(cfg, date)`：在 `prev_bars` 外面套一层**交易日历校验**
  （bars 最新日必须 == calendar 里 `< date` 的最大日）。不满足就整块不出涨跌幅，
  改在标题写「；涨跌幅未算（行情最新 X 日）」。实测本地能造出把 9 个月 +45%
  标成当日涨幅的情形，这就是必须堵的。
- `_chg()`：`+X.XX%`，价格贴住 limit_up/limit_down（半分钱内）时补 `涨停`/`跌停`。
- 涨跌幅基准 = **价格 vs 前一交易日收盘**。仿真账户 `cost_price` 恒为 0，
  算不出持仓浮盈亏，只能算当日涨跌幅；这点在推送里没解释，靠"vs X 日收盘"隐含。
- 格式：字段改用全角空格 `　` 分隔（钉钉 markdown 会折叠连续半角空格）；
  持仓按市值降序；块标题带"占净值 X%"。

测试 410 → 417（7 条新增，红态实测全挂）。已验证：服务器真实数据
（002164 昨收 17.99 → 卖 17.20 = -4.39%，000530 昨收 8.23 → 买 8.41 = +2.19%）全部对得上。
