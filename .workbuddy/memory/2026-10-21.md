## 因子研究脚本（新增 `scripts/factor_research.py`）

口径：不经回测引擎的纯收益计算（后复权、月频、等权、不计成本）。
输出三层：原始因子 IC/ICIR → 十分档多空 → **流动性三档内的长仓绝对收益**。

8 个因子（2020-2024，56 个有效区间），IC 全部同向：
```
mom_5      -0.0369 (-0.331)   十分档多空 -15.85%
mom_20     -0.0546 (-0.406)   -16.91%
mom_60     -0.0721 (-0.473)   -18.56%
vol_20     -0.1043 (-0.655)   -20.15%
vol_60     -0.1046 (-0.600)   -19.49%
max_ret_20 -0.0935 (-0.735)   -16.15%
log_amt_20 -0.1128 (-0.738)   -25.60%   ← 最强
illiq_20   +0.0767 ( 0.483)   +25.09%
```
即：动量、高波动、高成交额、大单日涨幅 = 下月跑输；规模/流动性是这段最强的单因子。

## 流动性分层是必需的（新硬规则）

三档等权绝对收益：低流动 1/3 **24.07%** / 中 14.50% / 高流动 1/3 **0.32%**。

高流动档内（最可交易）：低波 5 档 7.59% vs 该档等权 0.32%（+7.3pp）；
高波 5 档 -12.90%。低流动档内各档差别 <3%（那档整体 24%，什么都涨）。

**结论：低波/反转的作用是"剔除会崩的热门股"，不是"找到会涨的冷门股"。**

## 容量约束进选股 + 本金放大压力测试（推翻上一轮的静态估算）

新增 `strategies/filters.py::capacity_symbols`（约束：`rate × 20日均额 >= 权重 × AUM`），
`LowVolatility` / `EqualWeightStrategy` 加 `capacity_aum`（默认 None，输出逐位不变），
CLI 加 `--capital` / `--capacity-aum`。

实测（等权 50 只）：
```
本金    容量约束  年化     Sharpe  MDD     截断成交   可选池
100万   关        9.15%   0.489  -36.0%   0.0%      4,677
1亿     关        8.85%   0.475  -36.4%   0.7%      -
1亿     开        7.05%   0.404  -36.0%   4.8%      4,627 (99%)
5亿     开       -1.30%   0.059  -47.7%  17.4%      2,626 (56%)
10亿    开       -3.23%  -0.029  -54.4%  20.5%      1,263 (27%)
10亿    关        7.46%   0.424  -36.4%  16.3%      -
低波：100万 6.46% -> 1亿 7.36%(关) / 7.18%(开)
```

**修正**：上一轮 `capacity.py` 给出"5% 分位 5.4 亿"**偏高一个量级**，
因为假设放大后还持有同一批股票；真实上限约 **1 亿**。
5 亿时 -1.30% 与沪深300 的 -1.11% 几乎重合 —— 容量约束把组合推成了大盘股组合。

**关键教训**：不启用容量约束的高本金回测会"悄悄少买"（10亿 有 16.3% 成交被截断），
净值来自权重与设计不符的组合，**不可解释**。容量约束必须在选股阶段生效。

**另一个方法论坑**：1 亿档 8.85% → 7.05% 不是容量成本，而是散列重抽样的噪声
（池子少几十只 → 截断位置变 → 整个 50 只组合被换掉，σ≈2.69pp）。
做 A/B 必须先固定组合再过滤。

⚠️ 近两轮已经两次"静态估算被实证推翻"，以后凡是容量/规模类结论，
不要只给解析估算，必须跑一遍放大本金的回测。

覆盖 4,490/4,711 = 95.3%，83 个行业，写进 instruments.industry）。**当前分类、非历史快照**。

暴露：**J66 银行 30.6%**（全池只 0.96%，32 倍超配），加电力 7.0% / 道路 6.3% /
水运 4.7% / 水务 4.1%，前五 52.7%（这些行业全池只占 4.6%）。

## 修法验证：行业中性选股（`--industry-neutral`）

每行业取 k 只最低波、跨行业等权（约 80 只）：
```
组合                年化    波动    Sharpe  MDD      归因差额  换手  成本
等权·全池（参照）   9.15%  23.67%   0.489  -36.02%   +0.79pp   3.0  0.26%
低波（非中性）      6.46%  12.89%   0.550  -15.68%   -0.00pp  19.2  0.56%
低波·行业中性 k=1   9.74%  15.44%   0.679  -22.47%   +4.08pp  22.4  0.85%
低波·行业中性 k=2   9.54%  15.32%   0.671  -20.09%   +4.07pp  18.3  1.12%
```
k=1 与 k=2 给出几乎相同的 +4.1pp → 不是参数凑的。

**边界（必须一起说）**：beta 0.47，2021-2024 是下跌市，绝对收益含低 beta 风格运气；
没有股指期货数据无法剥离。所以只能说"控制行业后仍有组内选择效应"，
**不能说"这是有 alpha 的策略"**。

因子表加"行业中性 IC"列：八个因子保留 80%~95%，max_ret_20（-0.735→-0.846）与
vol_20（-0.655→-0.752）的 ICIR 反而上升 → 因子不是行业代理。

成本教训：k=2 有 157 只、单只 6,375 元，最低佣金 5 元 ≈ 8bp，成本 0.85%→1.12%。
**100 万本金下持仓不宜超过约 100 只。**

## 方法论（本轮第三次自我推翻，值得写进长期约定）

1. 基准撞车（静态假设"代码唯一"错）；
2. 容量静态估算（假设"放大后持有同一批股票"错，偏高一个量级）；
3. 低波"真因子"（只看 IC 与同档对照，没做行业归因，错）。

必须同时给出：流动性分档内 + 行业归因后，还剩多少。

### 两个口径错误（都已修，且都推翻了旧数字）

1. **归因用了日频再平衡**：2015 年日频等权 +27% vs 月频 +18%，9pp 全是再平衡红利。
   `industry_attribution.py` 改月频后，样本内组内选择效应 **+4.08pp → +2.13pp**。
2. **"全宇宙等权 8.72%"是日频**，月频是 **9.84%**（随机 50 只 9.47%±2.57pp）。
   以后引用参照值必须写调仓频率。

### 数据质量坑

- gm 的 `adj_factor` 会被重置：000022 在 2018-12-26 从 3.5265 → 1.0（价格无跳空），
  000043 有 -0.38% 漂移。新增 `builders.drop_nonmonotonic_k` 剔除留痕。
- **2015-2019 的 `is_suspended` 全为 False**，停牌表现为"没有行情行"
  （2015-07-08 只有 1,466 只有 bar）。引擎把停牌持仓冻结在最后价格（复利补跌），
  纯算把它们从横截面均值剔除 → 差 7.8pp。引擎更接近现实。
  校验应按**缺行率**而非 is_suspended 判断停牌。
