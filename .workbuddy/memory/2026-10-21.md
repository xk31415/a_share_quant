做 A/B 必须先固定组合再过滤。

## 证伪"低波当风控底仓"（第五次自我推翻）

**beta 匹配**（beta×等权 + (1-beta)×现金，现金 2%/年）：
```
时段        beta   年化差    Sharpe差   回撤差
2020-2024   0.552  +3.12pp   +0.124   -1.36pp（低波回撤更大）
2015-2019   0.661  -3.33pp   -0.134   -5.50pp（更差）
2025-2026   0.492  -1.33pp   -0.217   -6.58pp（更差）
```
**波动率匹配**（股仓 65%/71%/66%）：2020-2024 低波四项全胜（+2.45pp/回撤+2.22pp），
2015-2019 与 2025-2026 全输（-2.63/-1.68pp，回撤 -2.7/-2.2pp）。

上下行捕获：2020-2024 0.70/0.59 有防御；2015-2019 0.55/**0.64**（下行跌更多）。

**结论：低波的回撤保护 100% 来自 beta 更低，没有额外防御效应。**
只有策略被设计出来的那一段全胜，两个样本外都不如"等权+现金"。

附带实盘细节：2020-2024 低波最长水下 **677 交易日（2.7 年）**，beta 匹配 325 天。

**降风险的正确做法**：w×等权 + (1-w)×现金。65% 股 + 35% 现金在两个样本外
风险调整后都优于低波精选，且不需要选股/换手/行业中性化。

## 累计教训

五次自我推翻：基准撞车 → 容量估算 → 低波归因 → 样本外失效 → 风控定位。
共同模式：**用一个点估计/局部指标下结论，没做归一化或反事实对照**。
以后凡是"X 有 Y 好处"的说法，先问：**有没有更便宜的方式得到同样的 Y？**
（这次答案是有：降仓位。）没有这一问，就会把 beta 当因子、把行业当 alpha。

2. **`--cash` 优先于 `--capital`**：总资产 = 现金 + 持仓市值，程序算。
   让用户手算总资产是最容易错的输入口径。
3. **幂等**：目标持仓回灌再跑必须零订单（有单测）。实盘最容易犯的错就是
   "每次跑都换一批单"，白交佣金还偏离目标。
4. 卖出也整手（只有清仓带零股）、停牌持仓冻结但占仓位、样本外持仓清仓、
   单笔 <2000 元不动、数据超 15 天拒绝出信号。
